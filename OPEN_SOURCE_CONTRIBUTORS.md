# Open-Source Contributors

Thank you to everyone who contributes to GitHub Achievement Hunt. Use this page to recognize contributions made to the project.

## How to add your contribution

1. Add a row to the table below through a pull request.
2. Include your GitHub username, a link to your GitHub profile, a concise description of your contribution, and the date of your contribution in `YYYY-MM-DD` format.
3. Keep the description factual and limited to work you contributed to this project.
4. Remove the clearly marked example row when adding the first real contributor.

This file is the designated contributor list; it does not restrict who can edit a copy in their own fork. Access to the upstream repository should be managed through repository permissions and branch protection.
